# private/newsletters: newsletter issues for the digest comparison (session 58)

Energy Research Warehouse (ERW). Put newsletter issues here (PDF, HTML or text, one file per issue, the issue's date in its
name). Everything in this folder except this README is ignored by git: their text never leaves this machine.

What a session does with them: for each issue, list its headline stories (titles only, no text copied), match them
against the ERW digest of the same days (docs/digest/), and report coverage both ways (stories the issue had that the
digest missed, and the digest's stories the issue lacked). Only the aggregate comparison is stored or reported; never
the newsletters' text, titles in bulk, or the files themselves.
