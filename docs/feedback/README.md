# Feedback log

Session 27. Where the ERW records what people say when they are shown it: the protocol for a demo, and one file per session of feedback. The site does not collect feedback; this folder does, by hand.

## The demo protocol

One person, 20 minutes, their screen or ours, the public site as it is that day. Say at the start: "Nothing here is finished. We want to know what is wrong, confusing or missing." Then show the pages in this order, and let them drive where they want to.

| Minutes | Page | What to show |
|---|---|---|
| 0 to 2 | `/` (home) | The price board, the digest's top five, the four paths (enthusiasts, investors, researchers, traders) |
| 2 to 5 | `/digest` | Today's ERW's Energy Digest: a headline, its source link, ERW's Numbers Today and a footnote, ERW's Fun Fact |
| 5 to 8 | `/markets` and `/prices` | One hub's day-ahead against real time; one price with its table and citation |
| 8 to 10 | `/grid` | Yesterday's peak, the forecast error, the 7-day demand with the temperature overlay and degree days |
| 10 to 13 | `/deals` and `/companies` | One deal expanded; a party name that links to its company row; the confidence clause |
| 13 to 15 | `/policy` | This week in policy; one action expanded to its read and its dropped fields |
| 15 to 17 | `/analysis` | ERW's Chart of the Week and why the rule picked it; one gallery template run with other parameters |
| 17 to 20 | `/ask` | Their own question, answered with its tables |

Keep the last minutes for the questions if the pages run long; the questions matter more than finishing the order.

## The five questions

Ask all five, in this order, at the end, and write the answers in their own words:

1. **What did you hope to find, and did you find it?**
2. **Which number or claim would you not trust, and why?**
3. **What would you use this for in the next month, and what is missing for that?**
4. **What confused you, and on which page?**
5. **Who else should see this, and what would make them come back each week?**

## Where notes go

- **One file per demo:** copy `TEMPLATE.md` to `YYYY-MM-DD-<role>.md` in this folder (for example `2026-10-02-energy-trader.md`).
- **Identify people by role only:** a role, an organization type and a place (for example "power trader, Houston utility"). A person's name goes in the file only with their consent, written as such.
- **Record what was said, not what we wish was said:** quote where possible, and mark our own interpretations as ours.
- **Commit each file after the demo.** When a note turns into a change, link the commit or session report that made it in the file's "Follow-up" section.
- **The tally below is updated by hand** when a file is added.
