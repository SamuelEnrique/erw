## What was checked and found right

- Every count of the four views on the tables of this machine: 2,539 of 2,615 figures inside half the last digit shown,
  the other 76 being row 7; 785 of 785 words (quarters, dates, authorities, the 255 names of the rankings) the same.
- A server without the internal token draws no figure, no row and no party's name, on any view, and asks the database
  nothing.
- No row of an internal table is in git with this work; the written figures hold no party's name and no party's figure.

  for (the panel's note gives the first day held).

  report.
