# Ruling alternatives: /impact, Local impact (17 November 2026)

Session 7706 (samueloldlaptop, claimed in `docs/state/ruling_alternative_claims.md`). For each line of `docs/reviews/ruling-impact-impact-2026-11-17.md` whose change is 1 percent or more, or that adds or removes a figure, the other choice is built on its own branch from origin/main, with a test that pins the figure under it. The branch number is the line's number in the impact file; lines are taken in the impact file's order, which is the order of the size of the change (a figure from nothing or to nothing first, then by percent, then the lines that only add cells). No branch asks to land; no default on main changed. This machine cannot build the site: each branch's page is held by its tests and by the page's own model (`site/lib/forecast.ts` run on `lib/forecastdata.ts`'s parameters, `site/scripts/alt-impact-figures.mjs`), and has one row in `docs/state/browser_reads_wanted.md` for its screenshot at 1280.

- **The figures are pinned on JEDI's multipliers** (`nlr_jedi_multipliers`, NLR's JEDI models, public) read from `warehouse/output` or the folder `ERW_TABLES_DIR` names; a test skips where the table is not on the machine. Each test runs the cases of the impact file: the page as it opens (200 MW of Texas wind), Lone Mountain Geothermal (Nevada), Silver Queen wind (Iowa), CPV Basin Ranch gas (Texas) and each state's default plant.
- **No model call** was made (spend USD 0).
- **The sweep of each branch:** the eight test files that name the forecast's modules (`test_session347`, `3938`, `412`, `4203_forecast`, `4219_forecast_faults`, `4221_forecast_readers`, `7506_impact_replication`, `7515_impact_read`), the node tests `test-forecast.test.mjs` and `test-impact-read.mjs`, and the type check.
