**The reader:** a fund analyst setting two hubs, or two grids, side by side (A and B) over the same months to choose where a project earns more.
**The five cases:** (1) a 200 MW solar farm: ERCOT West hub (A) against ERCOT Houston hub (B), the twelve months to September 2026, day-ahead and real time: the average price and the hours below zero; (2) a 100 MW, 4-hour battery: ERCOT North hub (A) against SPP North hub (B), the same twelve months, real time: the four-hour spread, the hours above USD 200 and each grid's carbon; (3) CAISO SP15 (A) against CAISO NP15 (B), September 2026, both markets at once; (4) NYISO's New York City zone against ISO-NE's Internal Hub, the twelve months; (5) ERCOT West hub's twelve months and its September 2026 set against the cost of power page's figure for the same hub.
**How it was read:** this machine cannot build the site. The whole page was drawn to HTML by calling the page's own function on the site's own file (`site/data/price_compare.json`, built 2026-11-16T11:36:35Z), with `next/font/google` stood in for (`site/scripts/font-stub-loader.mjs`, new), and read line by line with every hover. The shared figures were set beside the cost of power tool's own year files (`site/data/datacenter/<grid>_<year>.json`, built 2026-11-12) by a scratch script under `runs/`. Part A's rows (`docs/reviews/price-compare-faults-2026-11-16.md`, rows 1 and 2) are cited by number and not written again. **No figure of ISO-NE or NYISO is written in this file:** `hub_price_comparison` is held for ISO-NE, MISO and NYISO from 21 October 2026 (`site/data/license_status.json`), and the test holds this file to it.
