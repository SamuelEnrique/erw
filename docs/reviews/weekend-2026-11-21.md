**Run it:**

2. Put the tables in `docs/findings/_top40/tables/` (git ignores that folder). **What it prints:** each do-file's own output, then one table (also in `tables/run_top10.log`):

- `number` and `finding`: the sheet's number and a short name with its unit.
- `sheet` and `stata`: the sheet's figure for the last year, and yours.
- `result`: `match` (within 0.5 percent of the change, the draft's own tolerance), `differs`, `no figure` (your table stops before one of the two years) or `failed, error N`.
- **If a line fails:** `error 601` the table is missing or misnamed; `error 111` the CSV still has its `#` lines; anything else, paste it to Claude. The files were read, not run: no machine has Stata.
