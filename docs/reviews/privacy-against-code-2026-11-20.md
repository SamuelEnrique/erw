## Where they agree (read and found as written)

- **Cookies:** the only cookies the code sets are `erw_internal` (httpOnly, a digest of the token) and `erw_view`, by `/internal/unlock`, for 90 days, and `/internal/lock` clears them. No route sets a cookie for a visitor (`res.cookies.set` and `Set-Cookie` searched across `site/app`, `site/components`, `site/lib`, `site/proxy.ts`).
- **Browser storage:** only the battery game, two keys (`erw.battery.tutorial.v2`, `erw.battery.settings.v5`), never sent (`site/app/play/battery/Game.tsx`). No other file of the site touches `localStorage`, `sessionStorage` or IndexedDB.
- **Usage counts:** unchanged since session 5162 held the method note to the code line by line on 13 November (`tests/test_session5162.py` passes on 20 November); no file of the counts changed since.
- **No analytics, no advertising, fonts from the site itself:** no `@vercel/analytics` or other service in `site/package.json`; the font is `next/font/google`, which the build downloads and the site serves itself; the enforced policy lets a browser load scripts from the site and cdnjs only, images and fonts from the site only.
- **Ask:** the log line of a question holds the time, the grid, the question, the outcome, a question number, its cost and its timings; no address, no user agent, no identifier. The cost ledger holds the question's number and cost, not its words.
- **The daily codes in the database:** a rate count a day old and a day's question counts are deleted the next time a request is counted (migrations 028 and 023, 035), as both pages say.
