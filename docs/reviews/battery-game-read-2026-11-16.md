# The home battery game (`/play/battery`) read as the reader it is for (chain 304, part B, session 7551, 16 November 2026)

**The reader:** a student, or a new analyst, who plays a named day and then asks what a real battery of that size would have earned; and a teacher who sets the game for a class. Not a developer or a lender: the battery, the home and the fleet are fictional and the page says so; only the prices are real.
**The five cases:** (1) a student plays Winter Storm Uri, 15 February 2021 (ERCOT, the hub average), on Normal with the default battery (13.5 kWh, 5 kW), then asks what the perfect battery earned and what a real battery would have; (2) the same student plays the August 2023 ERCOT heat, 10 August 2023, on Hard, and checks the day's prices against the event page; (3) a student plays the CAISO duck day, 24 July 2026 (SP15), on Easy, and asks how much of the score is market money and what California's real fleet is; (4) a teacher sends a class of 30 to Uri's day on Normal so that every score lands on one leaderboard; (5) a new analyst sets the section "The fleet: fictional and real" beside `/storage`, `/cost-of-power/battery/awards` and the grid page.
**How it was read:** this machine cannot build the site. The end screen, the debrief, the preview, the fleet section and the day's link were drawn to HTML with the page's own components (`site/scripts/battery-game-figures.mjs`, session 7535, and this session's `site/scripts/test-battery-game-read.mjs`), every play recomputed by `lib/battery.ts`'s own `optimum` and `simulate`, and every figure set beside the tables of this machine (`event_window_daily`, `battery_stack_stress_daily`, `storage_capacity`, the main copy's `warehouse/output`). Not seen: no click, no hover and no layout in a browser, no canvas, and not the live set's today's level (the worktree has no key). The server page (`page.tsx`) is async and was read as source; its fleet cards were moved to `RealFleet.tsx` so that they draw.

Part A's rows (`docs/reviews/battery-game-faults-2026-11-16.md`) are cited by number and not written again. No figure of a license-held grid is in this file: every row cited is ERCOT's, CAISO's or the game's own (`site/data/license_status.json`: `event_window_daily` and `iso_hub_prices_history` are held by grid for ISO-NE, MISO and NYISO only; `storage_capacity` and `battery_stack_stress_daily` are public).

## What this reader still cannot get from the tool, and why

- **What a real battery earned on the day.** The game's model is a home battery on the hub's real-time price; a real battery's money also holds ancillary services, its own node's price, contracts and charges no public file gives by day. The page now says so and points to the battery page's model of a grid battery (row 2).
- **The fleet on the day played.** The fleet section is the EIA's latest inventory (row 4); the fleet at the level's month waits on the builder (row 6, data request 239).
- **The event on Easy.** The link to the event page stands on Normal and Hard (row 7, a ruling).
- **A score net of the starting charge.** The game rule counts it (row 8, a ruling).
