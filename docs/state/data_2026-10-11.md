## The commands

Run on `lab-desktop` in the checkout that holds the tables, with `.venv\Scripts\python.exe`. None is piped; each exit code is in the session report.

```
python scripts/sync.py --check --no-git > runs/session200/sync_check.out 2>&1
python scripts/data_state.py --data-root . --sync-out runs/session200/sync_check.out --day 2026-10-11 --reasons docs/state/data_2026-10-11_reasons.csv --notes docs/state/data_2026-10-11_notes.md --ceiling-log runs/data_machine_daily.out --out docs/state/data_2026-10-11.md
```

- Rows, first, last: each table's CSV in `warehouse/output`, one pass by `scripts/data_state.py` (`file_state`).
- Interval, license, last run: `warehouse/metadata/coverage.csv`. Archive: `warehouse/metadata/archive_manifest.csv`. Redivis: `warehouse/metadata/redivis_uploads.csv` and the saved output of `scripts/sync.py --check --no-git`.
- Daily run: `warehouse/metadata/run_status.csv` and `warehouse/metadata/table_migrations.csv`; the data machine's steps from `warehouse/run_data_machine.sh`.
- Public site: `warehouse/supabase/live_set.yaml`. Paused publishers: `warehouse/metadata/paused_sources.csv`. Known gaps: `warehouse/metadata/known_gaps.csv`.
- ERCOT's ceiling: the line the daily refresh writes into its own log.
