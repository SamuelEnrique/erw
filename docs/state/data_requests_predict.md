This window writes no warehouse table and takes no data lock: each table the forecast should have in the warehouse's record, and its step in the daily run, is a row here for window A, which holds the data lock. Every table asked for here carries the tier `derived` (a model's output, computed by ERW code; `docs/datastandard.md`, "Provenance tiers") and never enters a layer 1 table unmarked. Window A marks a row done with its commit; no row is waited for.
