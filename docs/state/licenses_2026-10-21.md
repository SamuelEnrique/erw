# The license table for 21 October 2026

Energy Research Warehouse (ERW), session 248. Written by `python scripts/license_state.py` on 2026-10-14 from four sources and nothing typed: `warehouse/metadata/coverage.csv` (every table and its flag), `warehouse/metadata/license_status.csv` (the tables flagged public whose publisher asks for permission, session 207), `warehouse/metadata/license_tables.csv` (each table's publishers) and the site's own code (which tables each page reads, `scripts/page_tables.py`). `python scripts/license_state.py --check` says whether it still agrees with them.

## Read these first

- **199 tables: 125 public, 40 "license needed", 34 internal.**
- **From 21 October 2026 a "license needed" table shows those words on the site in place of its numbers,** unless a permission is recorded in its row of `warehouse/metadata/license_status.csv` (the columns `permission` and `permission_ref`, filled by a person). Nothing changes before that day. The public day moved from 20 to 21 October by the ruling of 12 October 2026, night (`docs/roadmap.md`); this session moved the status file's day with it.
- **2 pages go dark and 17 go partly dark.** Dark: every table the page reads is held whole. Partly: some of its tables are held, or a table is held for some grids' rows only, and the page keeps the rest.
- **35 of the 40 tables are held by grid, not whole:** their deciding publishers are grid operators, so the rows of those grids read "license needed" and the other grids' rows stay. The other 5 are held whole.
- **Who decides:** NYISO (29 tables); ISO-NE (25 tables); MISO (22 tables); Bloomberg (4 tables); Data Center Dynamics (4 tables); Data Center Frontier (4 tables); Financial Times (4 tables); Hart Energy (4 tables); and 16 more publishers.
- **A recorded permission turns a table back on by itself:** write the permission into the table's row, run `python scripts/licenses.py status` and this script, and land.

## What this table cannot say

- **It reads names in code.** A table a page reads through a name built when the page runs is missed; a table named in a page's data file counts as read. The page's own code, through `site/lib/license.ts`, decides what a visitor sees.
- **A verdict is a session's reading of a publisher's sentence** (`docs/licenses.md`), not legal advice.
- **`/ask` and the data catalogue read every table of the live set,** so each held table is held there too, whether or not a page is listed for it.
