# Rulings of 6 November 2026

Energy Research Warehouse (ERW). The owner delegated these five rulings to Claude in chat on 6 November 2026 (13:53 Pacific) and uploaded this file. Every chain reads this file as it reads the earlier `docs/state/rulings_*.md` files: each line below is a ruling, in force from this file's commit, until the owner changes it. Each is written so a session can act on it without asking.

1. **FERC-714 Part 3, Schedule 2 (the planning areas' forecasts): the pull is allowed.** It is a federal public-domain filing, held by FERC and republished by EIA; the "no new source" rule of chains 147 to 157 does not bar it, because the ERW already holds FERC-714's other parts and the source is the same publisher. The data machine pulls it (robots file first, as always), writes `ferc714_forecast_growth` as chain 157's sessions 2949 and 2950 described, license public.

2. **ERCOT's `/misapp` and `/misdownload` paths: no new request.** ERCOT's robots file disallows them, and a rule a machine keeps for every other host is kept for ERCOT too. The daily run's existing real-time price pull through those paths is a legacy the owner will review; no chain adds to it. The settlement point list (NP4-160), the DAM node list and the four coincident peak intervals' node prices are taken only through ERCOT's public API (api.ercot.com, which needs a free registration and key the owner has not made) or through a public mirror whose terms allow it; until a key or a mirror exists, the node basis stays as it is and the node-to-hub mapping stays out, said so on the tab with "source needed", no digit.

3. **Google's article-decoding endpoint for the Digest's resolver: not used.** No request to a Google endpoint whose terms the ERW has not read and accepted. The resolver improves only through the publishers' own feeds and pages where the feed gives the outlet's address (the outlet's own page first, as chain 149 left it); items whose only address is Google's keep "(via Google News)". The owner may reverse this after reading Google's terms himself.

4. **The large-load tariff table's license: public, row by row.** A tariff filed with a state commission or FERC is a public regulatory record, and a row whose source is the commission's docket or the filed tariff book is `public`, with the filing cited in the row. A row whose only source is a host whose terms ask written permission (IN.gov's statewide terms, AEP's "personal use only") is `internal` until the permission is on record, and the page shows it as the owner's rule says: the cell blanked with a footnote that a license is needed. The standard's row-level license flag carries this; the table's own license line reads `public (row-level holds)`.

5. **The landing requests of 6 November (rows 1 to 15 of `docs/state/landing_request_portable.md`): any machine with the memory may land them.** The desktop's second window lands them first; if a row has not landed by the time another chain's landing session runs (the personal laptop's overnight chain of 6 November at its sessions 7, 11, 16 and 19; the desktop's other windows at their landing sessions), that chain lands the row's holding branch itself (8 holds 1, 4 and 7; 11 holds 2, 3, 5, 6, 9 and 10; then 12, 13, 14, 15), through the full gate, one at a time, the row marked landed with the commit so no second machine repeats it. A machine that finds the row marked landed, or finds a `land/<task>` branch pushed within the last 90 minutes by another machine, leaves that row alone.
