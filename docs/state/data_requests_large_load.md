Energy Research Warehouse (ERW). Written by session 5300 (portable laptop window P4, 13 November 2026), branch `wip/5300-large-load`. This window writes no warehouse data. Each row below is a change only window A makes, because window A holds the data lock and settles licenses. Window A marks a row done with its commit.

The dataset is `docs/research/large_load/utilities_2026-11-13.csv`: one row a large-load rule of one utility, every value with its document, page or section and the words. The method is `docs/research/large_load/README.md`, and the hand check is `docs/research/large_load/spotcheck_2026-11-13.md`. It starts from window A's `large_load_connection_rules` (84 rows in the Redivis draft of 13 November 11:52 UTC) and `utility_large_load_tariffs` (95 rows), and does not repeat them. A field those registries already hold with the same value is written `held: <registry>/<file>.yaml`, a pointer and not a value. A field that differs is written with its new value, and the row's `erw_overlap` names the file.
