# Licenses: what each publisher's own page allows

Energy Research Warehouse (ERW), session 205, 12 October 2026. Written by `scripts/licenses.py write` from three files in `warehouse/metadata/` (`license_reads.csv`, `license_verdicts.csv`, `license_tables.csv`) and `coverage.csv`. Do not edit this file by hand.

- **What a verdict is.** A session read one page of each publisher, once, and took the sentence that allows or forbids redistribution. The verdict is that session's reading of the sentence. It is not legal advice, and no lawyer has read it.
- **Two verdicts a publisher.** "As the ERW is today": an open research project that sells nothing. "If the ERW sells anything": the same sentence read for a commercial product. They differ where a page allows noncommercial use only.
- **Nothing was changed in `coverage.csv`.** Where its flag and the verdict differ, the table is listed below and a person rules.
- **A publisher not read has no verdict.** A table that would otherwise be public is then "not settled", never public by default.
- **A quoted sentence is cut by code from the page as it was saved,** never typed. The pages themselves are a publisher's and stay on the data machine (`runs/license_reads/`).

## Read these first

- **283 tables.** The flag and the verdict agree on 196; a ruling settles 44 (session 324: the "license needed" rows of `license_status.csv`, and 2 tables kept internal by a ruling); disagree on 0; 42 are not settled (a publisher not read); 1 is internal by the ERW's own choice.
