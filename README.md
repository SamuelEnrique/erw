# erw
Energy Research Warehouse

The Energy Research Warehouse (ERW) is an open, harmonized energy data warehouse, modeled on the Item Response Warehouse (github.com/ben-domingue/irw). Start with [`ARCHITECTURE.md`](ARCHITECTURE.md), then [`docs/datastandard.md`](docs/datastandard.md). Working rules are in [`CLAUDE.md`](CLAUDE.md); what to work on is in [`PRIORITIES.md`](PRIORITIES.md).

To read the tables from Python, use the `erw` client package in [`package/`](package/README.md) (`pip install -e package`).
